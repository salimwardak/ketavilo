## Content

The website contains 78,325 Gutenberg text editions and all 281 collection entries from the checked official Ganjoor EPUB index. Collection language is explicitly unknown when it has not been verified. The collection is not claimed to include every free Persian book worldwide.

There are 1,012 distinct book summaries: 12 original trilingual summaries plus 1,000 source-attributed Wikipedia plot/content summaries. 153 have Persian text; 12 have Pashto text. Interface language does not translate books or summaries. Wikipedia excerpts include attribution, revision links and CC BY-SA 4.0 notices.

Favorites, interface language, theme and selected reading progress are saved only in each visitor’s browser. Twelve classics have local complete texts. Other texts and collection downloads use the original source.

## Reading and PDF availability (Edition 8)
12 complete, locally hosted book PDFs are listed in pdf-manifest-v8.json. The PDF-only filter shows exactly these books. Other Gutenberg texts load in a sandboxed iframe without leaving Ketavilo; source connectivity is required and these texts are not locally hosted. Ganjoor collections use the public CORS JSON dataset, with categories and poems rendered inside the reader. Some older source entries may not exist in that dataset. There is no claim that all catalog entries have a PDF or that all external texts are individually verified.
